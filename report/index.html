Report

制作ログ・検証結果

対象期間

2026年5月2日〜5月6日

目的

AIツールを活用したLP制作フローの検証と、非属人化に向けた制作手順の整理

主な成果
  • ChatGPTでLPモックアップを生成
  • Figmaで正解データを作成
  • Figma MCPとClaude CodeをWindows / CMD環境で連携
  • HTML / CSS / JavaScriptでLP基盤を構築
  • FAQアコーディオン・TOPボタン・Googleマップ埋め込みを実装
  • GitHub共有に向けた構成を検討
課題
  • AI生成だけでは実務品質に届きにくい
  • 細かいレイアウト調整は人力修正が必要
  • Claude Codeは利用制限がある
  • 画像素材の整理とパス管理が重要
結論
「ChatGPTで方向性を作り、Figmaで正解データ化し、Claude Codeで実装し、人が最終調整する流れが現時点で最も実務向き」

Insights

Key Findings

01

AIは初速に強い

ChatGPTはモックアップ生成や構成案作成に有効。ただし、そのまま実装品質にするには追加工程が必要。

02

Figma正解データが重要

Figmaでpx・余白・素材・レイアウトを整えることで、Claude Codeへの指示精度が上がる。

03

Claude Codeは実装補助に強い

HTML / CSS / JavaScriptの構築や修正に有効。ただし、範囲指定と人力確認が必須。

04

非属人化の可能性

プロンプト・Figma構成・GitHub管理を整備すれば、今後のLP制作フローとして展開可能。
